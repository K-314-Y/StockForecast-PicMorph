# S110: 実データ取得候補と評価条件の監査

調査日: 2026-11-27 (JST)。公開されている公式仕様・利用規約のみの調査。契約者のプラン、キー、実データ、保存領域は確認していない。採点解禁・データ取得・契約変更・実売買は行わない。

## 結論と候補

- 個人向け J-Quants API V2: 契約者自身の私的分析・バックテスト・本人専用アプリに利用できる。Free は月0円・直近12週を除く2年、Light は月1,650円（税込）・5年。Free は同時点での前向き日次取得には使えない。過去の記録を後日取得して当時見えた値とみなさない。Light は候補であって契約済み・購入承認済みではない。本人専用の直接ローカル取得を第一候補とする。
- JPX公式カレンダー・相場表: 営業日・未調整の日報値の独立照合に有用。公開閲覧可能という事実だけでは、機械取得・保存・再配布・加工利用の権利は確定しない。配信遅延や訂正履歴も要確認。CAPTCHA/403 を迂回しない。
- DataCube: 個人・法人向けの都度購入型。JPXの比較表には二次配布可とあるが、目的のデータと利用形態に対応する個別条件・費用の確認が必要。前向き日次配信・当時版の保証は未確認。
- J-Quants Pro: 法人向け。外部配信を検討する場合は権利を含む契約条件と費用を問い合わせる。契約には法人格が必要で、標準契約での外部配信許諾を仮定しない。
- 2026-11-24 提供開始の公式リモートMCP (https://mcp.jquants.com/mcp) は ChatGPT/Claude 対応。契約プランの範囲のみ。旧ローカルMCPは新規配布終了、既存導入は継続可だが更新なし。チャットへの実データ送信は本プロジェクトでは引き続き禁止。MCPを使うだけで当時版の証明や権利確認にはならない。

## 権利と保存のゲート

J-Quants API 規約第7条・第8条、公式利用目的FAQに基づく。契約者本人以外へのデータ・継続的分析結果の提供や商用利用は禁止。個人の単発分析公開等には別条件があるが、当プロジェクトは公開・共有禁止を維持する。BYOK（各ユーザーが自身で契約・キーを用意）でアプリを提供する道はあるが、各人の環境内で取得・保存・分析し、提供者のサーバーに中継・蓄積しないこと、閲覧制限・明示・削除機能等が必要。取得データから得た知見や学習済みモデルを商品に組み込むことも不可とFAQに記載。公開リポジトリにはコード・架空データ・公開仕様の参照のみ。実データ・派生分析・キー・証拠本文は含めない。

契約終了時はデータ・復元可能な派生物・複製・バックアップを消去。ダウングレードでは上位契約のみのデータを消去。元値を復元できない派生物は非公開等の条件付きで保持可能。ゲームの固定記録/評価資料の不変性は利用権限より優先しない。契約状況、対象プラン、有効期間、利用者限定、消去対象の所在と安全な削除方法を確かめるまで実データを新規取得しない。既存データを無断削除しない。

## V1 の技術的な重大制約

1. 東証現物の通常終値は15:30 JST、J-Quantsの日足更新の目安は16:30 JST（保証なし）。固定 V1 は前営業日終値までの履歴で判断し、その前営業日終値で仮想売買する。終値観測後にその終値で約定する仮定は実行可能性を欠く。次の終値を知らずに確率を出すこととは別問題。V1 の合成・遡及実験は架空の売買ルールであって現実の取引成績の証明ではない。
2. J-Quants の調整済み価格は分割・併合で過去に遡って更新される。日足の実際の過去更新時刻、訂正前版、データ版番号は一般に取得できない。無料プランでも遅延期間中の分割により取得可能な古い価格が変更される。単一の最終36日系列と自己申告の available_at / observed_at だけでは各予測時点の実際の入力を証明できない。すべての将来分割で予測が変わると断定はしないが、訂正・丸め・企業行動もあるので当時版は保存する必要がある。
3. カレンダーAPIは Date/HolDiv を返し、休日やOSE祝日取引を含む。東証現物の営業日と区別し、JPX公式営業日・立会時間との照合を必要とする。日足の無約定は Null として返り得る。欠落・無約定・売買停止・上場廃止・取引所障害・訂正に対し、銘柄の後付け置換、前値補完、結果による除外をしない。
4. S105/S108/S109 は形式とファイルの一致のみ。資料・日時・権利の真正性は独立確認されていない。S104 の固定コード/プロトコル、V1評価条件と保存済み記録を変更しない。score_allowed=false を維持する。

## S111以降の V2 設計案（未承認・未実装）

- 新バージョンとして事前に固定。既存 V1 登録は再利用・書換えせず、合成テストで新しい計算順を検証する。過去の成績を見て条件を選び直さない。
- 予測精度: 前日までの実際に観測できたデータのスナップショットで、翌営業日の終値方向（前日終値基準）を予測し、確率評価を独立集計。予測確定時刻と入力の版を保存し、締切を超えた取得は予測に利用しない。
- 仮想損益: 上記判断を翌営業日の始値で執行するモデルに分離する。寄付き前に判断確定済み、無約定なし等が条件。始値での実際の約定は保証されない。ギャップ、取引手数料、保有ポジション、株式分割・併合、配当の扱い（価格リターンか総収益か）、評価終了時の清算を事前に規定する。取引コストと滑りの条件も明示する。
- 取得案: 通常は終値配信後に本人のローカル環境で取得し、実観測時刻・取得時刻・対象日・レスポンス内容のハッシュを保存する。予定更新時刻を実観測時刻として記録しない。各判断時点の入力系列・価格版を別記録にして、訂正を上書きしない。取得・利用可能時点の証拠と契約条件を確認した範囲のみ使用する。契約終了時の消去要件に従う。
- 既存10銘柄・24履歴営業日・12評価営業日の対照比較、同一期間、同一条件、採点保留の方針を維持。厳密な V2 の時刻/価格形式、日付境界、資金計算、欠測条件は次工程で合成テストによる仕様検討。実データ・学習・外部公開・実取引は別途明示承認が必要。
