## 1. ゲームの中心
株式やAIに詳しくない人が、2Dキャラの髪・服・アクセサリーや公開パーツを組み合わせてAIを作り、未来の**実際の株価**を予測し、仮想メダルの売買損益を楽しめること。過去相場リプレイ・架空相場は練習やテスト用であり、完成版Bの本筋とは混同しない。現実の証券注文や金銭交換は扱わない。ゲーム完成後は開発用のCodex・ChatGPT・Geminiに依存しない。

## 2. 設計確定事項（ユーザー質問1〜32の要点）
- キャラは基本2D。既存の共有パーツを組み合わせ、必要ならAIを使ってパーツ編集を補助する。3Dは扱わない。
- 外見特徴とAIは双方向に結び付く。色・形・服装・アクセサリーなどの特徴で、予測モデルの組み合わせ・特徴・学習方式・売買戦略が決まる。似た特徴は基本的に似た挙動とする。
- 予測は上下方向と価格変動の大きさ。外見からAIが生まれても、性能が高いとは決めつけない。予測精度・実際の仮想損益・最大下落率は独立に評価。AIの性能をゲームバランスのため意図的に弱体化しない。
- 初期対象は初心者にも知られた有名日本株の数十銘柄。将来米国株を追加。提供できる銘柄・時間粒度は使用許諾とデータ可用性に従う。
- 売買はプレイヤー手動、条件付きAI自動、AI完全自動。買い・空売り・倍率・銘柄選択を扱い、保有期限は原則設けない。ただし資産が尽きた場合は強制決済。
- 初期は一定間隔で注文を確定し、間隔を段階的に調整。将来は実際の市場に近い頻度。夜間・休日は予約とし、表示済みの古い価格で即時売買を認めない。
- 売買損益は実際に観測した株価の騰落率に基づく。**予測が的中した事実**と**メダルを稼いだ事実**は異なる。証拠となる予測日時・予測内容・モデル版と株価の観測時刻を残す。
- AIの売買戦略（投資割合・倍率・損切りの判断）はキャラ特徴で決める。一方、人間は各AIに渡すメダル額の上限を選ぶ。
- **各AIは独立した専用メダル財布を持ち、最大損失はその割り当てまで。** 他のAIや未配分メダルには損失を転嫁しない。各財布ゼロで強制決済。借金不可。手動売買は手動用資産全体が担保。
- パーツ編集で実質的な計算方法が変わると新世代AIが生まれる。旧世代の予測・株・メダル・実績は別に保持。見た目だけの微修正で新世代を乱立させない。
- プレイヤーは初期キャラを1体受け取り、一つパーツを編集して自分のAIを作る。制作中に予測/取引スタイルの変化がわかる。表情・動き・演出は後から差し替えられるようにする。
- メダル獲得はゲーム内仮想売買、アルバイトミニゲーム、他者が公開AIで利益を得た際の作者成功報酬。共有機能はキャラ一覧・成績表示から始め、後で検索・ランキングを充実させる。

## 3. 最初の完成基準：質問32=B
初期版の完成には以下を実機で検証できることが必要。単に純粋関数や試験用の架空相場が動くだけでは未達。
1. 初期キャラの編集 → 実際のモデルに反映 → モデル版を保存して再起動後も復元。
2. 適正に利用できる未来の日本株データを取得し、銘柄・株価・時刻・提供元を検証。過去データや架空価格を現況として表示しない。
3. 同じモデル版による先出し予測を固定して、未来の市場価格との照合・予測精度評価ができる。
4. 人間とAIの予約注文は受付後の将来の市場観測で決済。欠測/休場/遅延に際し、不正な即時約定をしない。
5. AI別の財布・仮想ポジション・損益・強制決済・成績を正しく保存して再起動後も追跡。
6. UIからキャラ→AI→銘柄→予測→自動売買→結果まで途切れず試せる。実際の金融取引は発生しない。

## 5. 今回の開発スライス
game_runtime/forward-paper.mjs と mcp/tests/forward-paper.test.mjs を追加。
- 仮想のAI別メダル財布。各財布にモデル版の識別子を固定。
- サーバー側が受け付けた注文は、それより後の観測時刻の株価でのみ成立。
- 価格欠測時は勝手に埋めず、注文を保留。
- 買い・空売り・最大25倍の計算の最小単位。
- 各AIの資金のみで清算、全額消失した財布はゼロに止める。他AIと未配分金額を守る。
- 取引結果と清算の履歴イベントをメモリ上に残す。
- **重要：テストの価格は架空の固定値。これだけでは実市場データ・本番自動運用・永続保存・画面接続を実現したことにはならない。** 1体につき同時保有は1銘柄の試験スライス。売買手数料・銘柄分散・資金再配分・公平な運用コスト、配信元の認証、複数ユーザーの同時更新は次段階。

## 6. 次の開発順序
P0: 株価データの更新頻度・利用許諾・出典・遅延を確認。適法に使用できるデータがなければ本番接続は保留し、最新相場として偽装しない。
P1: モデルの外見特徴→予測・売買戦略の決定的変換を保存できるようにする。キャラ改造前後のモデル版を分離。
P2: 信頼できる市場データ用のサーバー内部アダプターと予約注文の締切を実装。古い市場観測・重複注文を拒否し、閉場中は約定させない。
P3: 財布・注文・約定・予測のイベントを安全に永続保存し、再起動、重複実行、異常終了のテストを実施。保有中の出金・資金変更は未実装のまま誤認させない。
P4: 1体のAIで先出し予測から実観測、バッチ決済までを実機検証。複数銘柄/複数AI/空売り/倍率に拡張。
P5: 初心者導線と簡単な表情・結果表示を接続。公開AI・ランキングは完成版Bの後に段階的に追加。
