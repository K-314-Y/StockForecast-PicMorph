# P9ag 実測前の研究計画（2026-11-25）

起点は dev/forward-game の 5c2a5bb。従来の架空価格は日別ハッシュでほぼ独立な ±350 bp の変動を与える。今回はゲーム内の既存判断が、方向や変動幅に時間構造を与えた場合にどう振る舞うかを調べる。主仮説は「急落後の回復では売られ過ぎを見る眼鏡が、標準および常に現金より平均損益を改善する」。

## 固定系列

開発用 development と検証用 validation の各組に各タイプ60例（番号0〜59）、計720例。抽出後の選別なし。seed は ASCII の P9ag-20261125-v1。乱数 U(k,m) は文字列 `seed/set/type/i/k` の SHA256 を符号なしビッグエンディアン整数に読み、m で割った余り。番号と日 t（0〜11）は十進・ゼロ埋めなし。日ごとの雑音 E(t,a) = U(t,2a+1) − a。価格は共通のゲーム履歴の末尾109.00から開始し、毎日整数セントで floor((前値 × (10000 + 日次bp) + 5000)/10000) に更新する。

|タイプID|日次bpの生成規則|
|---|---|
|up（上昇）|+110 + E(t,180)|
|down（下落）|−110 + E(t,180)|
|flat（横ばい）|開始値へ約半分戻る力 floor((10900 − 前値セント) × 5000 / 前値セント) + E(t,110)|
|recovery（急落回復）|急落日 j = 2 + U(shock,3)。j より前は E(t,80)、当日は −900 + E(t,80)、以後は +140 + E(t,100)|
|cluster（変動性持続）|初期状態 U(state,2)（1が高変動）。2日目以降は U(flip-t,5)=0 で状態反転、それ以外は継続。高変動日は E(t,450)、低変動日は E(t,50)|
|reversal（途中反転）|転換日 j = 5 + U(turn,3)。初期方向は偶数番号で +1、奇数で −1。当日から符号反転。方向 × 160 + E(t,120)|

## 比較と判定

既存ベンチと同じ窓3/9、trend 重み100、他0、全強度100。標準・星・眼鏡・リボン・無装備の移動平均・3装備均等・常に現金。全群同一価格・初期1000C、自キャラ配分100%、LONG時35%、手数料0.1%。当日判断は前日終値まで。最終日は時価評価。ゲームが返す手数料込み損益を同一例内で対応付ける。

各組・タイプ・方式で平均・中央値損益、各例の最大下落率の平均と最悪、平均取引日数（比率調整を含む）、平均手数料を表示。標準比・現金比それぞれの厳密な改善例数、平均損益差と点別95%近似区間（例ごとの差の標本標準偏差を用い 平均 ± 1.96 × SD / √60）を記録する。同額は改善に含めない。主仮説だけを判定し、開発・検証双方で両対照との差の区間下限が正なら、この生成条件での研究仮説を採択する。他は現行維持。その他の比較は探索的で、多重比較補正のない区間から方式を選ばない。

共通履歴、固定したドリフト・回復時期・振幅、空売りなし、12日という短さ、各タイプ同数という設計が結果を左右する。タイプ名は生成過程を表し、判断器の入力にはしない。区間はこの生成器での例間変動の目安。実市場での頻度、優位性や順位への外挿は対象外。
