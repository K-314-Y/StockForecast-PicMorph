# S112: 取得時点ごとの価格記録（合成試作）

個人専用・ローカル限定。S111の翌日始値方式に向け、取得時点によって価格系列が変わる場合を別々の保存記録として扱う試作を追加した。実データ取得・本番記録の作成・時刻の認証はしない。V1の固定条件や既存データには触れない。

- 10銘柄・履歴24日（架空の平日、240行）を含む3種類の組込み合成記録: 初回、訂正版、翌朝の開始後に観測した遅延版。
- 各記録は観測時刻、想定する翌日始値時刻、価格系列のハッシュ、全記録のハッシュ（ファイル名）を持つ。合成時刻であることと採点禁止を明示する。
- 明示的に指定した所有者専用0700のテスト用ディレクトリの中で、0600ファイルに排他的な一時書込み・同期・上書き禁止の原子的公開を行う。同じ記録の再保存は同一IDを返す。異なる訂正版は別ID。指定IDの内容・形式・権限を照合し、リンクや破損を拒否する。
- 予測に使う版は明示IDで読む。観測時刻より前の判断、始値時刻以降の判断、未存在・破損した版は拒否する。最新記録への自動差替えはしない。
- 固定の合成データ以外は受け付けない。CLI、実データ入力、ゲームAPI、バックグラウンド取得は未接続。価格系列・判断時刻の証明、公式営業日、訂正履歴、企業行動、利用権限の確認や実データの保持・消去機能は別工程。

検証: python3 -B -m unittest discover -s mcp/tests -p 'test_synthetic_observation_store.py' -v
