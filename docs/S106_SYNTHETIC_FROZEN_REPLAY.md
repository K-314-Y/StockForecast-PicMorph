# S106: 固定モデルの合成データ計算テスト

S104の固定記録と同じ構造のテスト用記録をメモリ内で作り、正規化JSON・SHA-256・固定プロトコルを検査する。実在の登録や証跡を作らない。固定した元モデル、基準、候補を既存の Python replay_window に渡し、Node の runSyntheticGame と summarizeWindows で同じ架空価格を比較する。

```sh
node --test mcp/tests/frozen-accessory-replay.test.mjs
```

10銘柄の識別子はプロトコルと同じだが価格は完全な合成値。日付は架空の平日ラベルで正式な営業日ではない。各銘柄24日の履歴・12日の評価、各モデル10000仮想コイン・手数料0.1%で、Brier・仮想損益・最大下落率・判断差を比較する。各予測は次の終値を観測する前の履歴だけを使用する。最後の未観測価格だけを変えても確率・判断が変わらないこと、同じモデル同士は全項目で同点になること、繰り返し結果が一致することをテストする。Brierと判断閾値は確率の記録から独立に再計算し、売買・手数料も実際に発生する架空シナリオにする。固定モデルが同一の対照テストは装備効果の検証ではない。

既存の計算コードと固定プロトコルは変更しない。実行は組み込みのテストシナリオに限られ、任意の価格・実登録・データパッケージの指定、HTTP経路、結果保存、XP・コイン更新、データ取得は実装しない。S105の準備状況は依然として採点禁止。公式カレンダーの網羅性、権利・利用可能時点、価格調整の根拠と実際の約定可能性は未検証であり、合成結果は予測精度の証明ではない。実データを評価する処理・承認経路・結果画面は別工程とする。
