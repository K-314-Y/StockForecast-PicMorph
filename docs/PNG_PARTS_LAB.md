# PNGパーツ実験室（Sprint 83）

実行画面：ゲームの「外見からキャラを作る」→「私のイラストを重ねる」→「PNGパーツ実験室を開く」、または同じローカルサーバーの /parts-lab/preview.html。

## この実験でできること

- 自作、または改変・利用許可のあるPNG/WebPを**ブラウザだけ**で合成する
- 必須：顔の描かれていない体と、背景透明の通常顔
- 任意：うれしい顔、しんぱい顔、前髪、服
- レイヤーの重ね順：体→服→顔→前髪
- 1コマを緩やかに動かす、または横並び6コマを指定速度で再生する
- 表情切替、顔だけのXY微調整（±24px）、一時停止
- 自作素材がまだない場合は、Creature Lab独自デモから派生させた固定WebP 4点を明示的に読み込んで試せる

素材は同一サイズの**キャンバス全体**で書き出す。6コマの場合は6枚を横一列に連結した画像を、体と各表情のすべてに使用する。1コマの縦横は32〜1024px。ファイルはそれぞれ最大5MB。顔・前髪・服は背景を透明にする。通常顔以外の表情を省いたときは通常顔を再利用する。

## ZIPキャラのアクセサリー

ZIPのコマ数を選んでからZIPを読み込む。既定は従来の横並び6コマ。装備したアクセサリー（最大3個）ごとに、表示用の静止PNG/WebPを任意で選べる。重ね絵なしでも分析装備を登録でき、「重ね絵だけ外す」を押しても分析装備は有効。

重ね絵は5MB以下、縦横1〜1024pxで、透明またはほぼ透明な画素が1割以上あり、見える絵が必要。プレビューでは前髪の上に装備順で重ねる。横・縦位置は中央を0%、移動できる両端を±100%とし、拡大率は25〜200%。絵全体がコマの中に収まるよう制限する。各コマで位置と大きさは一定で、キャラの動きに追従させる処理は行わない。

プレビュー上で重ね絵の見える部分をマウスや指でドラッグすると、横・縦位置の数値欄も更新する。重なった部分では、触れた位置で見えている最前面の重ね絵を動かす。数値欄はキーボードでも調整できる。1コマのプレビューは編集中は上下に揺れ、ドラッグ中はその場で止まる。重ね絵を編集できる間は、プレビューの外側からページをスクロールできる。

明示的に登録すると、選択した表情と重ね絵を最初のコマに焼き込み、12日間の練習で使う立ち絵として保存する。元の体・表情画像は変更せず、重ね絵ファイルや位置・拡大率は個別に保存しない。登録済みのZIPキャラはそのまま使える。

## 登録済みZIPキャラの見た目の再編集

上部の「登録済みZIPキャラの見た目を編集」からキャラを選び、「見た目を編集」を押す。保存されている体・表情素材からプレビューを組み直し、同じ分析装備に表示用PNG/WebPを再添付して位置・大きさを調整する。「見た目の変更を保存」から確認を確定した場合に限り、**同じキャラIDの完成立ち絵だけ**を更新する。キャラ名、予測AI、分析装備、元の体・表情素材、ゲーム結果は変更しない。

**重要：** 従来の登録記録は合成済みの立ち絵だけを持ち、アクセサリーの画像・位置・拡大率、登録時に選んだ表情・顔位置を保存していない。従来の重ね絵は自動復元できないため、残したいものは再アップロードする。編集中の合成では通常の顔・初期顔位置を使い、未添付の重ね絵は差し替え後の立ち絵から消える。以前の立ち絵は確認前なら維持され、競合がある場合は409エラーで上書きしない。**保存後に元の立ち絵へワンクリックで戻す機能はない。**

## 実装・プライバシー

実験室は /parts-lab/preview.html と固定許可リストにあるスクリプトを配信する。ローカル素材はファイル入力とブラウザの createImageBitmap() で読み取り、canvasの drawImage() で合成する。画像の保存は明示的なZIPキャラ新規登録または登録済み立ち絵の再編集保存を確定したときだけ行い、保存先はこのPC。画像のAI認識や生成、外部サービスへの送信は行わない。

デモボタンを押した場合だけ、ゲーム内の固定画像4点を同じローカルサーバーから取得する。画像はページを閉じるか解除すると ImageBitmap.close() で解放する。prefers-reduced-motion 指定時は静止画像を表示。サーバー側は Content Security Policy、no-store、nosniff、X-Frame-Options DENY を適用する。ユーザーの元画像、local_state、既存の表情画像を改変しない。

## 未実装・限界

- 顔のない体画像を**自動生成・自動分割する機能ではない**。元絵に顔が描かれていると二重になる
- 1枚の静止画を使った場合、揺れるのは全体であってLive2Dのように関節や髪を個別変形できない
- 6コマの顔を固定1枚で流用する方式は実装していない（コマ位置がずれるため）
- 画風やキャラが著作権上安全であることの自動判定はできない。他人の素材を少し加工しただけでは許可にならない
