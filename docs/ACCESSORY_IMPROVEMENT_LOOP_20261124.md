# アクセサリー予測AIの改善ループ（2026-11-24）

## 判断

**実験案「分析結果の強さで重みを変える方式」は、収益改善としては採用しない。**
装備ごとに異なる判断が出ることと、その判断が有益であることは別の問題である。予測AIの本番実装、プレイヤー保存情報、通常ゲームのキャラには変更を加えない。

## 実験A: 方式の現状比較

`node scripts/benchmark-accessory-ai.mjs --count 240 --set main` と `--set holdout` を同じ条件で実行。初期1,000コイン、架空の12日間、手数料込みで、列の値は平均損益（コイン）。

| 分析方式 | main 240ケース | holdout 240ケース |
|---|---:|---:|
| 標準 | -1.34 | -2.14 |
| 星（ボリンジャー） | -2.16 | -2.49 |
| 眼鏡（RSI） | +0.49 | +0.39 |
| リボン（MACD） | -1.85 | -2.12 |
| 無装備（移動平均） | -0.92 | -0.99 |
| 3種均等 | -1.22 | -1.65 |

3種均等は標準より平均で +0.128 / +0.495コインだが、どちらの組も収益自体がマイナスである。眼鏡は取引頻度が非常に低く、損益だけで優れた予測と断定できない。取引しない基準（損益0、下落0）も判断時に必ず考慮する。

## 実験B: 新しい重み付け候補

`node scripts/benchmark-accessory-weighting.mjs --count 240 --set development` と `--set validation` を実行。価格と基礎モデルをそろえたペア比較。

| 指標（強度重み付け − 従来の均等重み付け） | development | validation |
|---|---:|---:|
| 平均損益の差 | -0.290コイン | -0.151コイン |
| 平均損益差の95%近似区間 | [-0.807, +0.226] | [-0.618, +0.317] |
| 平均最大下落率の差 | -0.051ポイント | -0.052ポイント |
| 下落率差の95%近似区間 | [-0.088, -0.014] | [-0.083, -0.021] |

ベンチマークに95%近似区間と判定値を追加した。これは正規近似による**架空シナリオ内の不確実性の目安**であり、実株価での予測性能や実取引でのリスク低減を証明しない。

- **仮説**：強い分析の比率を増やすと、均等重み付けより平均利益が増える。
- **反証となった観測**：開発用・未使用組とも平均損益差がマイナスで、利益改善の証拠はない。
- **別の発見**：両組とも平均最大下落率は小さくなった。リスク調整の研究対象にはなるが、収益改善の名目で既存方式に適用しない。

## 次からの開発ルール

1. **基準を固定**：同一の初期資金・12日間・手数料・価格系列で現行方式と比較。無取引を含む基準も併記。
2. **仮説は1つ**：どの分析の何を変え、どの指標が改善するはずかを先に記録する。外見やUIの改修と混ぜない。
3. **開発用で試し、未使用組で確認**：相場の条件を後から選ばない。平均利益、中央値、最大下落率、取引回数、費用、改善ケース数、不確実性を報告する。
4. **改善の採否を明示**：利益向上を主張するなら未使用組でも改善の証拠が必要。リスクを優先するなら利益低下との交換条件を明示。結果が悪ければ戻す（現行維持）。
5. **実株価については別検証**：架空相場だけでは予測精度は確認できない。先読みがない履歴データ、時系列の分割、実際の手数料を使うまで投資上の優位性を主張しない。
6. **次の「次」ではまず前回の仮説・結果・却下理由を確認**。機能を増やすだけの作業を改善ループと呼ばない。

## 次の検証仮説

同じ予測でも無駄な売買が増えれば手数料で平均損益が落ちる。**取引を控える条件**を研究用の候補として比較し、無取引にするだけで見かけの成績が良くなっていないか、取引日数・下落率・利益を一緒に評価する。実データで根拠が得られるまで本番モデルは変更しない。
