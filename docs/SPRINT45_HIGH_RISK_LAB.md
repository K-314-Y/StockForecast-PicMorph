# Sprint45 架空ハイリスク比較CLI

**架空・実資産非連動・期待値の証明ではない。** このCLIは無料ゲーム内コインの経済ルールを観察する独立実験。実際の投資収益やAIの予測能力を評価しない。勝率は生成した架空経路での結果にすぎない。

## 実行

作業ツリーのルートから、追加依存なしで実行する。

```bash
node scripts/sprint45_highrisk_lab.mjs
node scripts/sprint45_highrisk_lab.mjs --seed 45 --samples 20 --refill compare
node scripts/sprint45_highrisk_lab.mjs --seed 123 --samples 1 --refill off
node scripts/sprint45_highrisk_lab.mjs --help
```

| 引数 | 範囲 | 既定 |
| --- | --- | --- |
| `--seed` | 整数0〜4294967295（乱数種。同じ値で同じ結果） | 45 |
| `--samples` | 整数1〜1000（10連戦シナリオ群の数） | 20 |
| `--refill` | `compare` / `off` / `on`（給付の比較／なし／あり） | compare |

正常結果はstdoutだけに出し、ファイルには保存しない。不明・重複・範囲外の引数や不正な数値はstderrと終了コード1で通知する。生成・集計が完了してから出力するため、数値異常で途中までの結果を正常結果として出さない。

## 固定した条件

- 初期3,000コイン、1戦12日次ステップ、10連戦。各比較行で倍率1/5/10/25と投入比率0.1/0.5/1.0を固定する。給付有無を含めて24条件。
- seeded PRNG（再現可能な擬似乱数）で価格と売買判断を一度生成し、全条件に同じシナリオ群を渡す。条件や財布に応じた経路の引き直しはしない。
- 各戦の開始価格100。次の価格は直前価格に `1 + (乱数 - 0.5) × 0.12` を掛ける。売買判断は次の価格を生成する前に別の乱数でLONGを75%、CASHを25%として選ぶ。この比率は勝率ではない。
- 架空AIシグナルは固定生成した比較用の判断であり、実モデルの推論ではない。3キャラに同じ判断を渡し、mineに100%配分、他2体は0%。リスク比率1、売買手数料率0.1%。
- `runSyntheticGame`で投入分の日次資産推移を計算し、その`equity_path`を`settleLeveragedPractice`に渡す。日次財布は決済関数の`allocated_equity_path`に未投入分と端数を加えた値。独自の売買計算は追加しない。
- ロスカットは投入分がゼロになった日次観測で運用を終了する処理。同じ戦の後続価格が上昇しても復活しない。日中の約定は再現しない。損失は投入元本までで、未投入コインは保護される。利益上限はない。

既存UI・API・コイン計算、利益キャップの実験関数には接続しない。シーズンリセット、換金可能な価値、実XPの付与は今回追加しない。ネットワーク・外部サービス・サーバー・local_stateへのアクセスはない。

## 整数投入と復帰給付

既存決済関数は整数コインの投入額・利用可能額を要求する。利用可能額は`floor(wallet)`、投入額は`floor(利用可能額 × 比率)`とし、小数端数は保留して財布に戻す。投入額0の戦は両純粋関数を呼ばずスキップする。スキップは新たな投入全損には数えない。

給付ありでは、戦の開始時に **`Math.floor(wallet) < 1`** なら3,000コインを固定額で加算する。残存端数を消さず、財布を3,000に上書きしない。例えば残高0.63なら次戦は3,000.63となり、全額比率で3,000を投入し0.63を保留する。厳密な0も同じ給付条件に含む。1コイン以上あり、選んだ低い比率の切捨てだけで投入0になる場合は給付しない。最終戦後に新たな給付はしない。

給付は比較用のみ。**繰り返す無限発行はゲーム経済の均衡を破る危険がある。** 10戦で最大9回の給付を行える実験に限定し、運用ルールへの採用を意味しない。換金価値も実XPも与えない。

純損益は`最終財布 − 3,000 − 給付累計`。例えば0.63まで減った後に3,000を受け取り、以降損益なしなら最終財布3,000.63、純損益−2,999.37。給付を利益に含めない。

## 表示と集計

サマリーは各条件の全シナリオ群を集計する。各戦の詳細・日次財布は先頭の1群10戦を表示する。`--samples 1`なら全観測戦が詳細に表示される。

| 指標 | 定義 |
| --- | --- |
| 平均・中央値の財布／純損益 | 各10連戦の最終値を集計。純損益は給付を控除 |
| 全損率 | 投入分の最終資産が0の実行戦数 ÷ 実行戦数。スキップを除外 |
| 厳密ゼロ群数・率 | 戦の終了時に一度でも財布が厳密に0になった連戦数と割合 |
| 投入不能群数・率 | 戦の終了時に一度でも財布が1未満になった連戦数と割合。厳密ゼロを含み、ゼロだけの統計とは別に表示 |
| 実行率 | スキップしなかった戦数 ÷ 全観測戦数 |
| 再試行率 | 給付回数 ÷ (9 × シナリオ群数)。ゼロ／端数から次戦を再開した頻度であり、勝率ではない |
| 平均給付 | 連戦あたりの総発行量の平均 |
| 最大下落率 | 日次財布の過去最高値からの下落割合の最大値。集計欄は全群中の最大。給付前の残高も含む、給付調整なしの財布の推移 |

戦ごとに給付前残高・給付額・投入額・損益・終了残高・投入全損・厳密ゼロ・投入不能・スキップ・ロスカット日・投入分最大下落率・13点の日次財布を表示する。

セント単位の丸めは既存関数の出力を受け継ぐ。既存関数の投入上限10億コインや、安全にセント単位を表現できる数値範囲を超えたら、利益を切り詰めず実験を中止する。
