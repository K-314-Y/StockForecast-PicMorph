# P9ah 反発を保証しない急落市場での眼鏡RSI

**主仮説は不採択。** 6種類を等しく扱うと、眼鏡は標準より開発・検証とも平均5.73 C多く残したものの、初期1000 Cから開発で平均5.64 C、検証で5.17 Cを失った。現金との差の95%近似区間は両組とも全体が負だった。生成規則、評価単位、採否は実測前に固定した。[事前計画](ACCESSORY_CRASH_BRANCH_PROTOCOL_20261125.md)

弱い回復と正負混在の回復では眼鏡の平均損益が両組で正になった。下落継続では120例すべてで取引して損失を出し、平均は開発 −29.09 C・検証 −28.55 C、最悪は −40.98 C・−36.43 Cだった。二段急落でも平均損益は −12.21 C・−13.01 Cだった。

急落後にいったん反発して失速する枝では、眼鏡は上昇日の開発118/166日（71.1%）、検証101/159日（63.5%）を現金で迎えた。最終値が急落終値を上回った例に絞っても、上昇日をすべて逃したのは10/28例・7/23例だった。12日間を通じて一度も取引しなかった割合は、眼鏡では両組とも5/360例（1.4%）。途中失速で1/60例、正負混在で4/60例、残る4枝では0/60例だった。

## 測定条件と再現

各組で60個の急落履歴から6枝を生成した。計720本の12日系列について、同じ価格で5方式を比較した。主判定では6枝を共有する親が標本単位で、各組の標本数は60。下表の枝別区間は同一価格内の損益差に対する点別95%正規近似区間。損益・手数料はゲーム内コイン（C）。「終値回復」は急落当日の終値を上回ったケースを指す。

AIと現金には既存ゲーム会計を適用した。単純買い持ちは初日に350 C分を1回だけ買い、手数料0.35 Cを払い、数量を固定した。各終値で同じ初回買付をゲーム会計で時価評価し、初期資産と12日分の評価額から最大下落率を求めた。初日の投入割合をそろえており、買い持ちの翌日以降の保有比率は価格に応じて動く。

リポジトリのルートで `bash scripts/run-accessory-crash-study.sh` を実行する。P9agの予測・会計・モデルをコミット `b7cd646` から一時ディレクトリに読み出し、テストと実測を行う。判断器が参照するのはP9agと同じ設定と各判断の前日までの価格履歴で、分岐名は価格生成と事後集計だけに使用した。

P9agでは急落直後から毎日価格が上がった。今回は急落後の下落・失速も含めたため、売られ過ぎで保有した後にも損失が生じた。6種類の等重み、値幅、急落の時期、共通の初期履歴は研究上の設定である。検証組の別系列による再測定も同じ生成器内の検証であり、実市場の優位性や順位への一般化はできない。本番ルールは現行維持とする。

P9ag固定コードで9テスト成功（既存3、新規6）。720系列の再生成、両組を通じた重複の検査、全120親で観測履歴が同じ日の判断一致、当日以降の価格を差し替えても判断が変わらないこと、買い持ちの手計算、反発の数え方、親単位の区間を検証した。全件を2回実行して集計表・採否の標準出力が一致した（SHA256 `f61f8e6b4a13090d5c18b572255ff0a811a9709d107d7f3e327c2746d9ea31e0`）。
