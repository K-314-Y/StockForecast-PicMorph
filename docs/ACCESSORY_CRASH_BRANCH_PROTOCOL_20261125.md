# P9ah 回復を保証しない急落市場の事前計画

起点は dev/forward-game の b7cd646。P9agでは急落後の全日が正のリターンとなり、眼鏡RSIが現金を上回った。今回は同じ急落に続く6種類の展開を等しく重み付けした場合にも、眼鏡の12日平均損益が現金と標準の双方を上回る、という主仮説を1つだけ検定する。

## 固定生成規則

新規seedは P9ah-crash-forks-v1。開発 development・検証 validation の各組で親番号 i=0..59。各親に以下の6枝すべてを生成し、結果に応じた再抽出はしない。U(key,m) は ASCII の `seed/split/i/key` のSHA256を符号なしビッグエンディアン整数として m で割った余り。E(key,a)=U(key,2a+1)−a。日 t=0..11。数値キー部分は十進ゼロ埋めなし。ゲーム共通履歴の末尾10900セントから、前日セント価格 p を floor((p × (10000+日次bp)+5000)/10000) に更新する。

急落日 j=2+U(shock-day,3)。t<j は E(pre-t,80) bp、t=j は −900+E(shock-size,80) bp。この日まで枝IDを使わない。以後 k=t−j（1始まり）、枝別ノイズは e(a)=E(枝ID-k,a)。急落終値を q とする。

|枝ID|急落翌日からの日次bp|
|---|---|
|weak 弱い回復|+35+e(90)|
|stall 途中失速|最初の2日間は +180+e(90)、以後 −65+e(90)|
|flat 横ばい|floor((q−p)×5000/p)+e(60)|
|decline 下落継続|−120+e(80)|
|double 二段急落|k=3+U(second-day,3) に −650+e(80)、他の日は +40+e(110)|
|mixed 正負混在の回復|最初の2日は一方 +220+e(100)、他方 −160+e(100)。U(mix-order,2)=0なら正を先に置く。3日目以後は +70+e(240)。終値の回復は条件にしない|

## 比較と採否

P9agと同じモデル・暖機履歴、資金1000C、LONGの日の期首保有目標35%、売買手数料0.1%、終値時価評価。既存の眼鏡・標準・3装備均等、常に現金と、初日だけ350C分を買って0.35Cの手数料を払い数量を固定する単純買い持ちを比較する。買い持ちの初期リスクは同じで、その後の保有比率は価格とともに動く。判断器は枝名・急落日・親番号を受け取らず、その判断日の前日終値までを使う。共通急落を観測した直後を含め、観測履歴が同じ間は各方式の判断が全枝で一致することを検査する。

- 主判定は親ごとに6枝の「眼鏡−対照」の手数料込み損益差を平均する。親60個の平均 ± 1.96 × 標本SD / √60 を95%近似区間とする。開発・検証とも現金比・標準比の計4区間の下限がすべて正なら、この等重み生成条件で採択。それ以外は不採択。枝別成績や別の対照で主仮説を置き換えない。
- 各組・枝・方式で損益平均、平均最大下落率、平均取引日数・手数料、取引ゼロ例の割合、対現金・対標準の対応差と同じ方法による点別区間を集計する。下落継続では眼鏡の損失例数と最悪損益も報告する。
- 反発取り逃しは事後の診断指標。急落翌日以降で前日比プラスだった日のうち、眼鏡がその値動きの前に現金を選んだ日数 / 上昇日数を枝別に集計。加えて、急落終値より最終値が高い例のうち上昇日を1日も保有できなかった例数を表示。分母ゼロは該当なし。これらは実現可能な追加利益を表す指標ではない。

6枝の頻度・値幅、時期、モデルの暖機履歴は人工的に固定する。タイプ別結果は事後の説明であり、プレイ時に将来のタイプを選別できない。実市場の優位性・発生頻度や本番変更の判断には外挿しない。
