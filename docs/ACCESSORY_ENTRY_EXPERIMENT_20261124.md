# P9ae 売買抑制の比較実験（2026-11-24）

## 実験前に固定する条件
仮説：現行3装備均等分析で保有判断が2日連続した場合だけ保有を開始し、現金判断では直ちに終了すると、取引費用が減って平均利益が改善する。
- 現行、2日確認、常に現金の3群。初期1000コイン、リスク35%、手数料0.1%、同じ架空12日間。手数料ゼロでも再計算する。
- 開発用と検証用の独立した固定シード各240例。ルールと採否基準は両組で固定。現在と過去の判断のみ使用。
- 平均損益差の95%正規近似区間の下限が現行および現金基準に対して両組とも正なら改善候補。それ以外は現行を維持。実市場の証明ではない。
- 研究用のみ。既存予測・会計・キャラ保存・実市場接続は変更しない。
- 取引回数には毎日の比率調整を含む。費用ゼロの比較でも、保有期間の差は残る。

実行：node scripts/benchmark-accessory-entry.mjs --count 240 --set development（validationも同様）
