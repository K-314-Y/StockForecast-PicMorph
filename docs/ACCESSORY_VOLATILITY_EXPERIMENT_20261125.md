# P9af 変動性に応じた資金配分（2026-11-25）

## 実験前の固定条件
- 仮説：同一の3装備均等AIの保有判断で、直近5日リターンの二乗平均平方根（RMS）に反比例した配分が、同程度の平均投入比率の一定配分より最大下落率を減らす。
- 保有時の配分は 0.35 × 0.02 / RMS を15〜55%に制限する（RMS=0なら55%）。現金判断では0。判断時点までの価格のみを使う。
- 新しい固定シードの開発用240例、検証用240例。既存の12日架空価格生成器、初期1000C、手数料0.1%、同じ判断列。開発用の保有日の平均配分だけで一定配分の比較値を決定し、検証用には固定して適用。利益を使って調整しない。
- 比較対象：現行35%、開発用で平均配分を合わせた一定方式、変動配分、常に現金。全日平均の目標保有率を比較し、実際の約定直後の保有率も測定する。
- 採否：開発・検証の両組で、平均実保有率の差が1パーセントポイント以内、下落率のペア差の95%近似区間上限が0未満、損益差の95%近似区間下限が-0.5C以上（初期資金の0.05%）。これらは研究上の仮基準であり、実相場の安全性を保証しない。
- 既存会計は固定配分用なので研究専用の計算を使用する。一定配分の全例でゲーム会計の未丸め残高列・取引回数と照合し、不一致なら停止する。
- 本番予測、既存保存データ、Freeze、並行作業の変更、実株価、外部通信は対象外。架空価格は独立に近い日次変動で、現実の変動の持続性は再現していない。
