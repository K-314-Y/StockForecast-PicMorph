# S111: 翌営業日始値での仮想売買（V2設計試作）

個人専用のローカルゲーム向け。S110の問題を踏まえ、固定済みV1を変更せず、新しい純粋な資金計算関数を追加。V2は未固定の試作で、ゲームAPI・画面・実データ評価には接続しない。

- 前日までの情報だけで判断を確定し、翌日始値で仮想売買する。予測確率の評価（前日終値から翌日終値への方向）とは独立。S106の合成予測をテストで再利用し、当日の始値・終値を予測器へ渡さない。
- 基準・候補は各銘柄10000コイン、同じ12日・始値・終値、手数料売買各0.1%。保有は翌日へ持ち越し、翌日始値で既存保有分を評価してからLONGならリスク比率へ調整、CASHなら全売却。買付は手数料込みで現金を上限とする。小数口数、空売り・レバレッジなし。最終日は終値評価のみ、清算は仮定しない。
- 最大下落率は開始時・各始値売買前後・終値の評価額から計算する。日中の最安値は含めない。計算は倍精度で表示丸めは未実装。極端な価格は合成テストの安全範囲で拒否する。実際の約定・流動性・滑り・配当・分割・訂正は未検証・未対応。
- 10銘柄分の合成データ、既存の確率判断を使用した比較、ギャップ、全額買付、欠測、最終終値の変更をテスト。結果は投資成績や実データの性能証明ではない。採点禁止フラグを維持。
- 次工程では実際に観測した時点ごとの入力版と締切、企業行動・欠測・時刻証明・利用権限を検討する。新V2プロトコルは仕様確定後に別途固定する。旧V1記録・データ・コードは変更しない。
