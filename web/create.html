✦ キャラ制作

パーツを組む ゲームへ戻る

絵のAI解析は未接続: イラストは外見、候補はあなたが選んだ性格・設定から生成

イラストと設定を添えて、3つのルールモデル案から下書きを残しましょう。学習済みモデルではなく、実相場対戦には参加できません。既存の3キャラとは独立しています。

1. 外見と設定

性格の対応表で期間・配分・感度を決定します。設定と外見のメモは保存のみで、文章のAI解析は行いません。性能・精度は未検証です。

2. 候補を選んで保存

保存後のDRAFTは変更できません。別の案は新しい下書きとして保存します。

3. 保存したギャラリー

この端末だけに保存（最大50件・画像合計20 MiB）。下書きから架空データの学習演習ができます。対戦用の配備は行いません。

4. 保存した練習版

固定架空40点での学習演習。実相場の能力を証明しない。検証期間は選択に使わない。

小さいBrierほど良い指標ですが、学習後の検証成績が元の案より悪くなる場合もあります。繰り返し比較でも過剰適合します。練習版は対戦対象外です。
